# Sales Data Analysis

## Project Overview
This project analyzes sales data using Python and data visualization techniques.

## Tools Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Dataset
The dataset contains:
- Order ID
- Order Date
- City
- Product
- Quantity
- Price
- Revenue

## Analysis Performed
1. Revenue by City
2. Product Performance Analysis
3. Monthly Revenue Trend
4. Correlation Analysis
5. Product Sales by City
6. Monthly Product Performance

## Key Insights
- Kolkata generated the highest revenue.
- Hyderabad generated the lowest revenue.
- Laptops were the top-performing product.
- Revenue varied across months.
- Product demand differed by city.

## Business Recommendations
- Increase inventory for high-performing products.
- Improve marketing in low-performing cities.
- Prepare for seasonal demand changes.
